# The demo of W#

This program shows every part of W#, the framework of the window, and of the system of its
plugins. Each part is here once, small enough to read in its sources (`examples/ww-demo` of the
repository), and each page of this guide names the sources of what it shows.

- [The window](window.md): the tabs, the command bar, the navigation row, the message bar, the
  status bar, the work in the background, a question, the settings, the themes, the translations
  and the drafts.
- [The plugins](plugins.md): a file opened by the plugin of its type, Open with, the context
  menu of a view, a view inside a view, the plugins of other languages and the cache of the
  blocks.
- [Embedded files](files.md): the pages of this guide, its translations and the samples the
  program carries inside its executable.

Start with the menu (the button at the right end of the tab row): New note, Open, Widgets, Start a
job, Ask a question, the submenus of the plugins, Settings and About are there. F1 brings this
guide back.
