# Демо W#

Эта программа показывает каждую часть W#, каркаса окна, и системы его плагинов. Каждая часть
здесь по одному разу и достаточно мала, чтобы прочитать её в исходном коде (`examples/ww-demo`
репозитория), а каждая страница этого руководства называет файлы того, что показывает.

- [Окно](window.md): вкладки, панель команд, строка навигации, панель сообщений, строка
  состояния, работа в фоне, вопрос, настройки, темы, переводы и черновики.
- [Плагины](plugins.md): файл, открытый плагином его типа, Открыть с помощью, контекстное меню
  просмотра, просмотр внутри просмотра, плагины других языков и кэш блоков.
- [Встроенные файлы](files.md): страницы этого руководства, его переводы и образцы, которые
  программа несёт внутри своего исполняемого файла.

Начните с меню (кнопка в правом конце строки вкладок): там есть Новая заметка, Открыть, Виджеты,
Запустить задачу, Задать вопрос, подменю плагинов, Настройки и О программе. F1 возвращает это
руководство.

Остальные страницы руководства не переведены и показываются на английском: так набор встроенных
файлов возвращается к английскому тексту, когда перевода нет.
