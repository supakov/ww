# W# 0.1.45

The first version of the numbering of 08.11.2026: the framework of the window (`ww-base`, `ww`),
the runtime of the plugins (`wwrt`), the stable interface (`stable/`) and the examples of a plugin
(`examples/`). From here an agent changes the third number of the version alone, the first and
the second change on the word of the customer.

## What changed

- The texts, the tests and the documents name no other program. A theme is of the format
  `ww-theme`; a theme of an earlier format of a program (`<name>-theme`) and a draft of one
  (`<name>-draft`) are still read.
- The history before this version is gone from `docs/releases/`.
