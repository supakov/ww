# W# 0.1.46

The context of a view and Open with.

## What is new

- `ww::tree::show_with_menu`: the tree with a context menu; a click of the secondary button on a
  row selects it and opens the menu a closure draws for its key.
- The interface of the plugins (`wwrt::plugin`): `Plugin::open_as` (a file as a MIME type of
  the formats of a plugin) and `opens_bytes`, `View::pressed` (a switch of the bar),
  `View::context` (the commands of the selection or the cursor), `View::offer` and `offered` (the
  bytes a view offers to the other plugins), `Request::OpenWith`.
- `wwrt::menus`: the context menu of a view and its copy in the menu of the window, Open with for
  bytes and for a file, the plugins of the type found first in the colour of the accent, then the
  others to try.
- `Plugins::all_for_file`: the plugins of a file in turn, the ones of any bytes
  (`application/octet-stream`, `mime::OCTET`) last, so that every file opens.
- `mime::sniff` names JSON.
- wwrt re-exports `toml_edit` and `quick_xml` for the plugins.
- The template of a native plugin shows a switch of the bar, the context menu and its text
  offered.
