# W# 0.44.0

The framework and the system of the plugins in a repository of their own, out of the one of
WinWeaver (0.43.0, wview 0.14.0): the code is the one of those versions.

## What is new

- The repository supakov/ww: `ww-base` and `ww` (W#), `wwrt` (the runtime of the plugins, out of
  wview), `stable/` (the stable interface and the crate `wview-stable`), `examples/wv-hello` and
  `examples/wv-mandelbrot` (the examples of a plugin), `docs/ww.md` and `docs/plugins.md` (the
  study and the interface; the plugins of wview went to supakov/wview).
- The programs take it as a git dependency of the branch `main`. `ww::SOURCES` and
  `wwrt::SOURCES` name the folders of the sources, for the tests of the translations of a program.
- One version for every crate of the workspace, `wwrt` included (it was the version of wview).
