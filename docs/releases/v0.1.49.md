# W# 0.1.49

The files of a program in a browser (the list of 09.11.2026, the second, item 1, for WinWeaver in a
browser).

## What changed

- **`ww_base::files`**: the door of the files of a program and of the libraries it takes (`read`,
  `write`, `exists`, `remove`, `list`); `jsonfile::read`, `jsonfile::write_atomic` and
  `ww::dialogs::write_file` go through it. Natively the disk as before; in a browser the backend
  of the page: its storage, and a download for a path under `DOWNLOAD`, so a save by a path works
  in a page when its dialog gives such a path.
- **The folder of the page over http**: `ww::store::preload` reads `files.json` next to the page and
  the files it names before the window starts (`ww::web::start` does it); the store, the file layer
  and the languages of `lang/` read them first.
