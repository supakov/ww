# W# 0.1.48

The MCP server in W# (the list of 09.11.2026, the second, item 2): the tools of a program and of
its plugins for AI agents and for a call by name, with their switches and options, the tab, the
command line and the tools of the window.

## What changed

- **`wwmcp`** (docs/mcp.md): the server of WinWeaver made general. A source of tools (the program,
  a plugin) names its tools with their schemas, groups, modes and the options they need; the
  configuration file `.wwmcp` keeps in its branch `plugins` the settings of each source: off, the
  tools and the groups that are off, the values of its options. The server checks them before a
  call, keeps the journal, writes the log `mcp-<date>.jsonl`; stdio and HTTP on the loopback with
  a token; `wwmcp::cli` starts it without the window with the options of the sources on the
  command line (`--KEY VALUE`, `--set SOURCE.KEY=VALUE`, `--off SOURCE[/TOOL]`).
- **A call by name** (`Server::call`): the program, a script to come and the plugins run any tool
  by its name; a plugin meets the switches and the options as a client does, the program does not.
- **The tab** (feature `ui`): the server, the sources with their switches, options, groups and
  tools, a call of a tool by hand, the journal and the details of a call, Open the log.
- **The tools of the window** (`wwmcp::window`): list, open, close and save the files of the tabs,
  and the program's own tools that act on its state, answered at the frames of the window.
- **The tools of the plugins**: `Plugin::tools`, `tool_options`, `call_tool` and
  `Host::call_tool` natively; `ww_tools_get` (a function of its own, with or without
  `ww_plugin_get`), `ww_tools` and `call_tool` of `ww_host` in `ww.h`, the macro `tools!` and
  `call_tool` in `ww-stable`. A plugin may have tools and no views.
- **A host of plugins** (`wwrt::host`): `HostMcp`, the tab `HostDoc::Mcp` and the item MCP server
  of the menu of the plugins, `serve_mcp` for `--mcp`.
- **The examples**: the demo serves the tools of its window, `new_note` and the tools of its
  plugins, in the window and with `--mcp`; `ww-hello` greets (an option), counts words and opens
  its sample through `open_file` (an access option); `ww-mandelbrot` (C) gives the escape of a
  point, the set in letters and opens its sample through `call_tool` (the option `limit`);
  `ww-grey` (stable Rust) gives the state of the cache.
- `ww::i18n::tr_any`: the translation of a text known at run time (the names a source gives).
