# W# 0.1.47

W# as an SDK of its own: the names of the repository alone, embedded files, the cache of the
blocks for every plugin, the type of some bytes found by the plugins, the parts of a host of
plugins, and a demo program with a plugin of each kind.

## What changed

- The repository names no other program. The stable interface is `stable/ww.h` with the prefixes
  `WW_` and `ww_` (`WW_API_VERSION`, `ww_plugin`, `ww_plugin_get`), its crate is `ww-stable`, the
  examples are `ww-hello` and `ww-mandelbrot`. The version of the native interface
  (`wwrt::plugin::API`) and of the stable one stays 1 until the first release.
- **Embedded files** (`ww::embedded`, `ww::embed!`, docs/embedded.md): a set of files of the
  binary of a program or a plugin, found by its path in the language of the interface, a folder
  next to the executable standing for its translations. A page of a set opens in a tab of the
  window (`ShellDoc::Page`, `ShellAct::OpenEmbedded`, `App::open_embedded`), and its links lead to
  the other files of the set. A plugin gives its set (`Plugin::files`, `files` of `ww.h`); the
  translations of a set (`lang/<code>/ui.json`) join the window.
- **The cache of the blocks** (`wwrt::blocks`): one cache of the program for every file read in
  blocks, within a budget, with its limits and its state; a `BlockFile` is shared and a part of it
  (`slice`) reads the same blocks. The bytes of `Plugin::open_bytes`, `View::offered`,
  `Request::OpenBytes`, `Request::OpenWith` and `Host::open_inside` are a `BlockFile`.
- **The type of some bytes**: the host knows texts alone (`mime::sniff`, `mime::text`,
  `mime::charset`); `Plugin::sniff` gives the types of the plugins and `Plugins::sniff` asks every
  plugin in turn. The signatures of images, programs, archives and documents went to the plugins
  of those formats.
- **The stable interface** (`ww.h`, docs/stable.md): the MIME types of a format, the files of a
  plugin, `open_bytes` of a source, `sniff`, the size of the table, and the table of the host
  given to `ww_plugin_get`: a file read through the cache, a part of a source, the state of the
  cache. `ww-stable` writes and reads all of it (`Plugin`, `Source`, `open_file`, `cache`). The
  instructions name the builds in C, C++, Rust of any toolchain, Zig, Go, Free Pascal and Delphi,
  and C#.
- **A host of plugins** (`wwrt::host`): the tabs of the files of the plugins and the page of the
  plugins, opening a file by its plugins, the bar and the menus of the view in front, Open with,
  Open the file with, the submenus of the plugins, the section Plugins of the settings with the
  trust and the cache, the command line of `--plugins` and `--probe`.
- `ww::textdoc`: a text file in the editor of egui (the search, the cursor, the draft, the line
  ends kept) and `read_text`.
- **The demo** (`examples/ww-demo`): every part of the window and of the plugins once, its guide
  embedded in English, Ukrainian and Russian; `examples/ww-grey`, a plugin of stable Rust;
  `build-all.cmd` packs the demo with its plugins; `tools/imports.py`.
- The documents of a public SDK: README.md, docs/plugins.md, docs/stable.md, docs/embedded.md,
  docs/design.md.
